# 🐍 Python Mini Projects Collection

This repository contains beginner-friendly Python projects demonstrating concepts like file handling, functions, loops, and conditional statements.

---

## 📂 Projects Included

### 1️⃣ 💰 Expense Tracker

A console-based Python application that allows users to record and manage daily expenses.  
The program stores expense data in a text file and calculates total spending.

#### 🚀 Features
- Add new expenses
- View all saved expenses
- Automatically calculate total spending
- Data stored permanently using file handling

#### 🛠 Concepts Used
- File Handling
- Functions
- Loops
- Conditional Statements

---

### 2️⃣ 🏦 Bank Management System

A console-based banking system that allows users to create accounts, deposit money, withdraw funds, and check account balances.  
All account details are stored using file handling for persistent data management.

#### 🚀 Features
- Create new bank account
- Deposit money
- Withdraw money
- Check account balance
- Persistent data storage

#### 🛠 Concepts Used
- File Handling
- Functions
- Loops
- Conditional Statements
- Basic Data Processing
