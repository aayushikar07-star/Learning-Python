# 💰 Expense Tracker

## 📌 Overview
Expense Tracker is a simple console-based Python application that allows users to record and manage daily expenses. The program stores data using file handling and calculates total spending.

## 🚀 Features
- Add new expenses
- View all saved expenses
- Automatically calculate total spending
- Stores data permanently in a text file

## 🛠 Technologies Used
- Python
- File Handling
- Loops & Functions

## ▶ How to Run
1. Install Python
2. Download this project
3. Run the file:

python expense_tracker.py

## 📂 File Used
- expenses.txt (stores expense data)
